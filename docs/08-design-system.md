# Design System

## Brand direction

MobCode should feel:

- trustworthy
- modern
- technical
- professional
- clean
- reliable

Avoid making the website look like a generic discount/account marketplace.

The visual identity should communicate:

> serious developer tools marketplace

## Primary palette

Recommended tokens:

```css
--color-navy: #0F172A;
--color-blue: #2563EB;
--color-blue-bright: #3B82F6;
--color-background: #F8FAFC;
--color-blue-soft: #EFF6FF;
--color-white: #FFFFFF;
--color-text: #0F172A;
--color-muted: #64748B;
--color-border: #E2E8F0;
```

## Usage

### Navy

Use for:

- logo
- primary headings
- navigation text
- important dark sections
- high-contrast UI

### Primary blue

Use for:

- primary CTA
- links
- active states
- important interactive elements

### Bright blue

Use sparingly for:

- hover/focus states
- highlights
- gradients where appropriate

### Background

Default page background:

```text
#F8FAFC
```

Cards:

```text
#FFFFFF
```

Secondary blue-tinted sections:

```text
#EFF6FF
```

## Design principle

Do not make the entire website blue.

Use:

```text
white / very light gray
        +
navy typography
        +
blue actions
```

This creates a more trustworthy and premium appearance.

## UI style

Prefer:

- moderate border radius
- subtle borders
- restrained shadows
- strong typography hierarchy
- generous spacing
- clear CTA hierarchy
- responsive layouts
- accessible contrast

Avoid:

- excessive gradients
- excessive glassmorphism
- giant glowing effects
- too many colors
- excessive rounded cards
- visual clutter

## Product cards

Product cards should make these immediately clear:

1. product
2. plan/duration
3. price
4. availability
5. key benefit
6. purchase CTA

## Trust signals

The site should visibly explain:

- how delivery works
- payment process
- support
- refund policy
- product terms
- what customers receive

Do not fabricate trust badges, reviews, customer counts, security certifications, or guarantees.

## Typography

Support Persian and Latin text well.

The chosen font stack must render Persian cleanly and maintain a professional developer-tool aesthetic.

## Accessibility

Target WCAG-conscious design:

- sufficient contrast
- visible focus states
- keyboard navigation
- semantic HTML
- accessible labels
- reduced-motion support where appropriate
